# 출처 자료: OpenTelemetry GenAI Semantic Conventions (업스트림 사본)

이 디렉터리의 `events.md`, `metrics.md`, `reg.md`, `spans.md`는 2026-09-18 기술 지형 리서치(`07-tech-landscape/09-evaluation-and-observability.md`, ADR-0022) 때 참고용으로 내려받은 OpenTelemetry `semantic-conventions` 저장소의 `docs/gen-ai/` 및 `docs/registry/attributes/gen-ai.md` 원문 사본이다.

- 출처: https://github.com/open-telemetry/semantic-conventions (Apache-2.0)
- 성격: 설계 산출물이 아니다. 프록시 차단 시에도 에이전트가 오프라인으로 속성·메트릭·스팬 이름을 대조할 수 있도록 보관한다.
- 규약 적용 제외: 이 디렉터리의 파일은 브리프 §9 문서 규약(frontmatter·구조·링크 검사) 대상이 아니다.
- 정본은 항상 업스트림이며, ADR-0022가 고정한 커밋과 다를 수 있으므로 인용 시 커밋 해시를 확인한다.
